# Examples

Every example runs offline by default (a mock brain, no API key), and most take a
real brain when a key is set. Start at the top.

## Start here

| Example | What it shows |
|---|---|
| [compute_lab](./compute_lab) | Answers verified by actually running them in the sandbox, watchable in the live dashboard. The flagship. |
| [architect](./architect) | A colony of specialists designs a real software architecture and returns a validated, structured result. Runs on Gemini. |

## Coordination at scale

| Example | What it shows |
|---|---|
| [distributed_colony](./distributed_colony) | Many worker processes drain one shared queue with no dispatcher. |
| [forest_vote](./forest_vote) | Many independent colonies solve one goal and vote. Consensus beats a single try. |
| [live_swarm](./live_swarm) | A self growing colony that lights up every part of the live 3D graph at once. |

## Learning and evolution

| Example | What it shows |
|---|---|
| [learning](./learning) | A colony that discovers its own specialist from verified outcomes. Stigmergic learning. |
| [learning_strategy](./learning_strategy) | The same learning applied to tool choice and decomposition choice. |
